# 측정 결과에 포함하는 Queue 경로 실패

500명 모두 인증과 barrier 출발을 완료했다. Queue join 2건은 HTTP 0 / EOF, 나머지 498건은 입장·예약 성공했다. cohort 기준 미완료율은 0.4%다. 예약 endpoint만의 성공률 100%(498/498)와 구분한다. reservation 도달 수가 N보다 적다는 이유로 운용 스크립트가 중단·기본 설정 복원했으나, 이는 인증 통제 실패가 아니라 측정 중 실제 결과다. 집계 기준을 수정하여 이 run을 포함하고 실패는 보존한다. 네트워크 EOF의 직접 발생 지점은 판단할 수 없다. Queue-depth 표본은 2개이고 간격이 길어 순간 깊이·drain 처리율 추론에는 사용하지 않는다.
